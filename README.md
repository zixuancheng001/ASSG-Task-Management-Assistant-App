# Task Management Assistant App (Python & Tkinter)

A desktop productivity application built with **Python and Tkinter** designed to help users organize, track, and manage daily tasks efficiently.
Engineered with a decoupled architecture separating business logic from the GUI for enhanced maintainability and scalability.

## My Contributions

1. Task Tracker & Real-Time Analytics
Urgency-Based Ranking - Implemented dynamic task sorting algorithms that prioritize tasks based on priority levels and remaining time until deadlines.

2. Category Management & State Synchronization
Category CRUD Operations - Developed full create, read, update, and delete functionality for custom task categories.

---

## Team Project Features
*As part of a collaborative team effort, the complete application also integrates the following modules developed by my teammates:*

Task Management & Validation - Full task CRUD operations (title, description, due date/time, priority, status, category) with automated date and time input validation.
Reminder & Notification System - Configurable desktop reminder alerts with custom scheduling and automated surfacing of pending tasks due within 3 days.
